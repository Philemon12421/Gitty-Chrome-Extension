## ✦ What is Gitty?

Gitty is a Chrome extension that turns two of the most tedious parts of shipping a project — **writing a README** and **explaining your code** — into a few clicks. Fill in your project details, pick an animation style, and get a polished, badge-ready README. Paste any snippet and get a line-by-line breakdown with syntax highlighting, structure analysis, and improvement tips.

## ✨ Features

<details open>
<summary><b>📝 README Generator</b></summary>
<br/>

- Complete, professional READMEs with badges, features, and install steps
- **4 animation styles** — Typewriter · Fade In · Slide · Glow
- **Import from GitHub** — paste a repo URL and auto-fill name, description, language, and license via the GitHub API
- Live preview with proper markdown rendering
- Copy to clipboard or save as `.md`

</details>

<details>
<summary><b>🧠 Code Explainer</b></summary>
<br/>

- Paste code in **17+ languages** — JS, TS, Python, Rust, Go, Java, C++, C#, Ruby, PHP, Swift, Kotlin, SQL, Bash, HTML, CSS, Solidity, and more
- **6 syntax themes** — Dracula, Tokyo Night, Monokai, Nord, GitHub Dark, One Dark
- Line-by-line explanations at **3 depth levels** — Simple, Detailed, Advanced
- Structure analysis, key-concept callouts, and improvement suggestions

</details>

<details>
<summary><b>🎨 Light & Dark Themes</b></summary>
<br/>

- One-click toggle in the top bar, remembered across sessions
- Every panel, badge, and code block adapts automatically

</details>

<details>
<summary><b>🕐 History</b></summary>
<br/>

- Auto-saves your last 30 READMEs and code explanations
- Restore any previous item with a single click

</details>

## 🚀 Installation

```bash
1. Open Chrome and go to chrome://extensions/
2. Enable "Developer mode" (top-right toggle)
3. Click "Load unpacked"
4. Select the gitty-extension/ folder
```

<tr>
<th width="50%">Generate a README</th>

<td valign="top">

1. Click the Gitty icon
2. *(Optional)* Import from a GitHub URL
3. Fill in project details
4. Choose an animation style
5. Click **Generate README**
6. Preview, copy, or save as `.md`

</td>
<td valign="top">

1. Switch to the **Explain Code** tab
2. Select the language
3. Choose depth + syntax theme
4. Paste your code
5. Click **Explain Code**

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl` / `⌘` `+ Enter` | Generate README or Explain Code (active tab) |
| `Esc` | Close settings panel |

<br/>

## 💾 Saving Your Work

| Action | Button | Result |
|---|---|---|
| Copy README | 📋 Copy | Ready to paste into your repo |
| Save README | 💾 Save .md | Downloads as `project-name.md` |
| Copy explanation | 📋 Copy | Full explanation text copied |
| Auto-copy | Settings toggle | Copies the README the moment it's generated |
