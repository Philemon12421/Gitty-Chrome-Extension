# Gitty — Animated README & Code Explainer

> Generate beautiful animated READMEs for your GitHub projects and get AI-powered code explanations with elegant syntax highlighting.

## Features

### ✨ README Generator
- Generate complete, professional README files with badges, features, and installation instructions
- Choose from **4 animation styles**: Typewriter, Fade In, Slide, Glow
- Live preview with proper markdown rendering
- Copy to clipboard or save as `.md` file

### 🧠 Code Explainer
- Paste code in **17+ languages**: JS, TS, Python, Rust, Go, Java, C++, C#, Ruby, PHP, Swift, Kotlin, SQL, Bash, HTML, CSS, Solidity, and more
- **Syntax highlighting** with 6 themes: Dracula, Nord, Monokai, GitHub Dark, One Dark, Solarized Dark
- Line-by-line explanations with 3 depth levels (Simple, Detailed, Advanced)
- Code analysis: structure, key concepts, and improvement suggestions

### 🕐 History
- Automatically saves your last 20 READMEs and code explanations
- Restore previous work with a single click

## Installation

1. Open Chrome and go to `chrome://extensions/`
2. Enable **Developer mode** (toggle in top-right)
3. Click **Load unpacked**
4. Select the `gitty-extension/` folder

## Usage

### Generate a README
1. Click the **Gitty** icon in your toolbar
2. Fill in your project details (name, description, features, install steps)
3. Choose an animation style
4. Click **Generate README**
5. Preview, copy, or save as `.md`

### Explain Code
1. Switch to the **Explain** tab
2. Select the programming language
3. Choose explanation depth and syntax theme
4. Paste your code
5. Click **Explain Code**

### Keyboard Shortcuts
- `Ctrl+Enter` — Generate README or Explain Code (on the active tab)
- `Esc` — Close settings panel

## Saving Your Work

| Action | Button | Result |
|--------|--------|--------|
| Copy README to clipboard | 📋 Copy | Ready to paste in your GitHub repo |
| Save as file | 💾 Save .md | Downloads as `project-name.md` |
| Copy explanation | 📋 Copy | All explanation text copied |
| Auto-copy on generate | Settings toggle | Automatically copies README when generated |

All generated content is automatically saved to your **History** tab for later access.

## Technology

Built with vanilla JavaScript as a Chrome Extension (Manifest V3). No external dependencies — everything is self-contained for security and performance.
